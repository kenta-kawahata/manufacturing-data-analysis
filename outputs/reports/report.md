# 製造業データ分析レポート

## 1. 分析目的
フライス加工中のセンサデータから、tool_wear（工具摩耗）を予測。

## 2. データ概要
- 出典：Kaggle Milling Tool Wear and RUL Dataset 
- 使用センサ：acoustic_rms, spindle_load, vibration_x/y/z

## 3. 手法概要
- EDA：データ理解、可視化
- 前処理：欠損値確認、特徴量作成（移動平均・合成特徴）
- モデル：LightGBM, RandomForest
- 評価指標：MAE, R²

## 4. 主な結果
| データ | MAE (test) | R² (test) |
|--------|:-------------:|:-----------:|
| 生データ | 1.829 | 0.640 |
| 生データ(振動データなし) | 1.874 | 0.634 |
| 移動平均(20個) | 0.226 | 0.991 |
| 移動平均(20個,振動データなし) | 0.400 | 0.982 |

## 5. 考察
- 振動センサは影響小、音響データが支配的
- 複数の加工データ（移動平均）を使用すると精度向上
- 1回の加工単位ではセンサー値のばらつき大
- 簡易モデルでも十分な精度を実現可能
